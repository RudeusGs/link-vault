# LinkVault

LinkVault is a personal resource management system that helps users organize digital resources such as links, files, notes, and code snippets in a clean vault-and-folder structure.

The project supports resource classification by type, folder organization, tagging, favorites, file upload to Cloudinary, in-app file preview, search/filter features, and a dashboard summary.

## Tech Stack

- Frontend: Angular
- Backend: Spring Boot
- Database: PostgreSQL
- Storage: Cloudinary
- Containerization: Docker / Docker Compose

## Main Features

- Create and manage vaults
- Create nested folders
- Store links, notes, files, and code snippets
- Upload files to Cloudinary
- Preview supported files directly in the app
- Tag and favorite resources
- Search and filter resources
- Dashboard summary
